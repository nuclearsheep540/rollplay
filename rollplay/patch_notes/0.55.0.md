## Map Tokens

- **NEW:** Character tokens on the battle map — drag your token from the party drawer onto the map and move it like a mini on a real table
- **NEW:** DM tokens for monsters and NPCs — create named tokens in the combat drawer with D&D sizes (Medium through Gargantuan) that scale to the map grid
- **NEW:** Live table feel — when someone picks up a token everyone sees it lift with a "held by" nameplate; first hand on the mini wins
- **NEW:** Anyone can move any token, just like a real table — the adventure log notes when someone moves another player's piece
- **NEW:** Tokens snap to the grid on gridded maps and place freely on gridless ones; right-click removes a token back to the drawer
- **NEW:** Tokens persist across pause and resume — every map in the session keeps its own board
- **FIXED:** Grid lines now render above fog of war, so cell references stay readable over fogged regions
