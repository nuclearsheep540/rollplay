# 02 — api-site: character config on the campaign, the characters rewrite, the party, ETL

> Read `00-agent-brief.md` first. Depends on PR 1 (`01-contracts.md`). Contracts installs
> by path and is not pinned; rebuild the api-site image after PR 1
> (`docker-compose -f docker-compose.dev.yml build api-site && … up -d api-site`) so the
> container has the new package. Every path below is relative to `api-site/` unless stated.

## What this PR does, in order

1. Campaign module gains the character config: a draft column, immutable version rows,
   save/publish commands, three endpoints, a components catalogue endpoint.
2. Characters module is **rewritten**: one table, one aggregate, values document,
   session-bound creation, component writes, keepsakes. Every D&D table, column, command,
   endpoint and test goes.
3. Session module keeps the **roster** (users) and nothing else; the **party** (characters)
   becomes a query over character rows, and `session_joined_users.selected_character_id`
   is dropped.
4. Campaign-level character selection and locks are deleted.
5. Game ETL sends config versions and values at Start and writes values cold at End.
6. One autogenerated migration.

## 0. Vocabulary — read this before writing a line

Three words, three jobs. They were conflated in an earlier draft of this plan; do not
re-blur them.

| Word | Means | Lives | Commands act on |
|---|---|---|---|
| **Seat** | A place in a *live game* where a player's meta is drawn. `seat_layout` in api-game, `campaigns.max_players`, the runtime seat card. | api-game, hot | — |
| **Roster** | The users at this table — who has joined the session. `session_joined_users`, `SessionEntity.joined_users`. | api-site, cold | **users** |
| **Party** | The characters in play at this table, and by ownership the users behind them: every character whose `session_id` is this session and which is not deleted. | api-site, cold — **a query, not a column** | **characters** |

**Party is not stored.** A character row already carries `session_id` and `user_id`, so a
`selected_character_id` column beside it would be a second copy of the same fact — the
mistake `sessions.active_game_id` was retired for ("liveness is a query, never a column",
CLAUDE.md). Creating a character bound to a session *is* joining the party; ejecting it *is*
leaving. There is no `add_character_to_party` command and no party field on the session
aggregate. `Party` survives as ubiquitous language for the **read model** served by
`GET /api/sessions/{id}/party`.

Party ⊆ roster, always: a character can only be created by a user already on the roster.

**Nothing in api-site may use the word "seat"** after this PR. Grep it when you are done;
every remaining hit must be `max_players`, or prose about what a *room* shows. The
notifier's log tag is `GAME_NOTIFY`, not `SEAT_NOTIFY`.

```python
class Character(Base):
    """Character aggregate root.

    User-owned; bound to one session (its table) and one campaign (its provenance);
    built against one published character config, a whole copy of which is embedded
    so the character renders after the campaign is gone (a keepsake). Component values
    live in `values`, keyed by component id. There are no rules columns.
    """

    __tablename__ = "characters"
    __table_args__ = (
        UniqueConstraint("user_id", "slot", name="uq_characters_user_slot"),
        CheckConstraint("slot IS NULL OR (slot >= 0 AND slot < 8)", name="ck_characters_slot_range"),
        # One character per user per party, alive or dead. Deliberately NOT qualified by
        # is_alive: a dead character stays in the party, rendered at its zero point, until
        # someone ejects it — so aliveness must not free the slot, or a user would hold a
        # dead character and a living one and the party would be ambiguous for that user.
        # This index IS the "one at a time" rule; no application code repeats it.
        Index(
            "uq_characters_one_per_party",
            "session_id", "user_id",
            unique=True,
            postgresql_where=text("session_id IS NOT NULL AND NOT is_deleted"),
            sqlite_where=text("session_id IS NOT NULL AND NOT is_deleted"),
        ),
    )

    id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    user_id = Column(UUID(as_uuid=True), ForeignKey("users.id"), nullable=False)
    slot = Column(SmallInteger, nullable=True)  # NULL = soft-deleted; see uq_characters_user_slot
    campaign_id = Column(UUID(as_uuid=True), ForeignKey("campaigns.id", ondelete="SET NULL"), nullable=True, index=True)
    session_id = Column(UUID(as_uuid=True), ForeignKey("sessions.id", ondelete="SET NULL"), nullable=True, index=True)
    config_version_id = Column(UUID(as_uuid=True), ForeignKey("character_config_versions.id", ondelete="SET NULL"), nullable=True)
    config_snapshot = Column(JSONB, nullable=False, server_default='{"version": 1, "components": []}')
    values = Column(JSONB, nullable=False, server_default="{}")
    display_name = Column(String(200), nullable=False, server_default="Unnamed character")
    is_alive = Column(Boolean, nullable=False, default=True, server_default="true")
    avatar_asset_id = Column(UUID(as_uuid=True), ForeignKey("media_assets.id", ondelete="SET NULL"), nullable=True)
    avatar_asset = relationship("MediaAsset", foreign_keys=[avatar_asset_id], lazy="joined")
```

### 2.3 Aggregate — `domain/character_aggregate.py` (rewrite the file)

Delete every value object (`AbilityScores` … `InventoryItem`). The aggregate:

```python
UNNAMED = "Unnamed character"

@dataclass
class CharacterAggregate:
    id: UUID
    user_id: UUID
    campaign_id: Optional[UUID]
    session_id: Optional[UUID]
    config_version_id: Optional[UUID]
    config_snapshot: CharacterConfig
    values: Dict[str, ComponentValue]
    display_name: str
    is_alive: bool
    slot: Optional[int]
    avatar_asset_id: Optional[UUID]
    avatar_focal_area: Optional[dict]      # hydrated from the asset by the repository, as today
    color: Optional[str]
    created_at: datetime
    updated_at: datetime
    is_deleted: bool = False

    @property
    def is_keepsake(self) -> bool:
        return self.campaign_id is None

    @classmethod
    def create(cls, *, user_id, campaign_id, session_id, config_version_id, config: CharacterConfig,
               values: Dict[str, ComponentValue], slot: int) -> "CharacterAggregate":
        """Raises ValueError (pairing) or ValidationError (shape); both are 400s.
        Completeness (axis 1): every Name configuration with required=True must have a
        non-empty text value — raise ValueError("Missing required: <label>, <label>")."""
        CharacterSheet(config=config, values=values)          # pairing: raises ValidationError
        missing = [c.label for c in config.components if c.type == "name" and c.required
                   and not (values.get(c.id) and values[c.id].text.strip())]
        if missing: raise ValueError(f"Missing required: {', '.join(missing)}")
        now = datetime.now(timezone.utc)
        aggregate = cls(id=uuid4(), ..., values=dict(values), display_name=UNNAMED, is_alive=True, ...)
        aggregate.display_name = aggregate.derive_display_name()
        return aggregate

    def derive_display_name(self) -> str:
        """Every Name value in config order, single-space joined; UNNAMED when none/empty."""
        parts = []
        for configuration in self.config_snapshot.components:
            if configuration.type != "name": continue
            value = self.values.get(configuration.id)
            if value is not None and value.text.strip(): parts.append(value.text.strip())
        return " ".join(parts) if parts else UNNAMED

    def set_component_value(self, value: ComponentValue) -> None:
        """One component. Pairs against the snapshot (ValidationError on mismatch),
        then replaces and re-derives display_name."""
        candidate = dict(self.values); candidate[value.component_id] = value
        CharacterSheet(config=self.config_snapshot, values=candidate)
        self.values = candidate
        self.display_name = self.derive_display_name()
        self.updated_at = datetime.now(timezone.utc)

    def replace_values(self, values: Dict[str, ComponentValue]) -> None:
        """Whole-document replace from the End ETL. Same pairing rule."""
        CharacterSheet(config=self.config_snapshot, values=values)
        self.values = dict(values)
        self.display_name = self.derive_display_name()
        self.updated_at = datetime.now(timezone.utc)

    def unbind_from_table(self) -> None:
        """Leave the table for good: no session, no campaign, no version pointer.
        The keepsake state, reached by ejection exactly as by campaign deletion. The
        snapshot and values are untouched — that is the whole point of embedding them."""
        self.session_id = None
        self.campaign_id = None
        self.config_version_id = None
        self.updated_at = datetime.now(timezone.utc)

    def set_alive(self, is_alive: bool) -> None
    def set_avatar_asset(self, asset_id: Optional[UUID]) -> None     # unchanged behaviour
    def set_color(self, color: Optional[str]) -> None                # unchanged validation
    def is_owned_by(self, user_id: UUID) -> bool
    def soft_delete(self) -> None                                    # is_deleted=True, slot=None
```

No `take_damage`, `heal`, `mark_dead`, `resurrect`, death saves, lock/unlock, `finalize`,
`set_creation_step`. The aggregate does not know what any component means.

`CreateCharacter` (§2.5) uses `sync_player` with the full character half when a game is
open; `EjectCharacterFromParty` uses it with none.

Two deliberate asymmetries in the eject order (§3.3), both worth keeping:

- **The value read raises; the room notify does not.** A failed read means the eject would
  lose the night's play, so it aborts and the player retries (`GameNotifierUnavailable` →
  **503**, "Couldn't save this character's current state from the running game; try again").
  A failed notify leaves a stale entry in a room that is re-read on reconnect, so it logs
  `GAME_NOTIFY` and the eject stands.
- **A pairing failure on the fetched values is not fatal.** The room was reachable; one
  stored value is malformed. Log it and keep what is cold rather than trapping the player
  at a table.

### 5.2 The backfill — `scripts/backfill_keepsakes.py`

A standalone script run inside the container, **not** a migration:


Behaviour, all through SQLAlchemy Core against the live engine (`shared/dependencies/db.py`
engine), in one transaction:

1. **Guard**: if the `characters` table has no `character_name` column (old columns already
   dropped), print `BACKFILL nothing to do: old columns absent` and exit 0. If it has
   `character_name` but no `config_snapshot`, print `BACKFILL run migration A first` and
   exit 1.
2. Select every row of `characters` (including `is_deleted` and `is_draft` rows — every
   row is kept) with its `character_ability_scores` joined to `dnd_abilities` ordered by
   `dnd_abilities.id`.
3. For each row compute, via the pure function `build_keepsake(row, ability_rows) -> dict`:
   - `config_snapshot` = a `CharacterConfig(version=1, components=[...])` with, in order:
     `NameConfiguration(id="name_1", label="Name", max_length=60, required=True)`;
     `HitPointsConfiguration(id="hit_points_1", label="Hit points",
     rules=IntHitPointsRules(minimum=0, maximum=max(hp_max, 1), starting=max(hp_max, 1)))`;
     one `AttributeConfiguration(id=f"attribute_{n}", label=<ability name from
     dnd_abilities>, minimum=1, maximum=30, default=None)` per ability row, `n` from 1.
   - `values` = `NameValue(text=character_name[:60])`,
     `HitPointsValue(state=IntHitPointsState(current=clamp(hp_current, 0, maximum)))`,
     one `AttributeValue(score=clamp(score, 1, 30))` per ability.
   - `display_name` = `character_name.strip() or "Unnamed character"`.
   - `campaign_id`, `session_id`, `config_version_id` = `NULL` (a keepsake; its old
     `active_in_campaign_id` is deliberately not carried — the character is at no table).
   - `is_alive`, `slot`, `avatar_asset_id`, `color`, timestamps, `is_deleted` unchanged.
   Validate the snapshot and values with `CharacterSheet` before writing; a row that fails
   is printed with its id and the error and **the whole run aborts** (nothing half-done).
4. `UPDATE characters SET config_snapshot=…, values=…, display_name=… WHERE id=…` per row

5. Every migrated character is a keepsake with `session_id` NULL, so no party survives the
   migration — current sessions have no characters in them, as decided. The roster's
   `selected_character_id` column is not cleared here because migration B drops it
   outright; the backfill must not touch it.
6. Print `BACKFILL converted <n> characters`. `--dry-run` prints the count and rolls back.
