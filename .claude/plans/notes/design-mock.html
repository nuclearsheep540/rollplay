One ground, two hairlines

Identity bar, formatting bar and canvas all sit on #0B0A09. Only 1px #37322F rules separate them, so nothing reads as a floating card and the drawer's translucency never shows through the writing surface.

Two bars, two jobs

Row one is which note — title as the picker itself, save status, new note, actions. Row two is this note's formatting. Today's title, dropdown and New note are three separate elements stacked above the editor; this folds them into one row.

Reading measure, only where it fits

The workspace centres the text at ~62 characters, as the reference does. The drawer runs full width — at 280–560px there is no margin to give away, so the same rule would just make the column narrower.

Alignment needs a new package

@tiptap/extension-text-align (MIT) is not currently installed. Undo and redo need no new package — UndoRedo is already registered and only lacks buttons.

Heading as a picker

H2 / H3 / Body collapse into one control that shows the current block's level, replacing two toggle buttons that never showed what you were already in.

Open question — the light page

/notes sits on the dashboard's light background today. A full-bleed dark editor means that page becomes dark. Shown here as dark end-to-end; the alternative is a light editor out of the game and a dark one inside it.
